Short story, first person

Every partner launch needed a lift read within a week. I built one framework for all of them, and caught about 30K customers sitting in both test and control before a VP saw a number. The feature now adds 7M new active members.

3

Exact v9 bullet

Auto-activation measurement: built the measurement framework behind a feature that today contributes 7M new active members, 5.5M of them engaged; the framework gave VPs the evidence to approve its expansion across 13 partners. Built in about a week, with presentations due within a week of each launch: joined experiment, streaming, website and subscription data from several Amazon systems with custom identity mapping; aligned 12+ stakeholders across 5 offices; found that reused experiment identifiers had put about 30K customers in both control and test, which would have invalidated the lift read, and fixed it with date-bounded assignment so the VP decision rested on clean cohorts. The framework became the standard for every partner and, in 2026, the base of a membership metric senior leadership tracks. Stack: Glue, Spark, Athena, QuickSight
