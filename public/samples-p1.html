Deal agent

Problem
Leaders wanted several deal models before locking a partnership, and each one took weeks in Excel.
Built
An LLM agent on 20+ live data sources. The LLM only routes, Python computes every number, and each run ends in a dashboard leaders can change.
Result
Replaced about 6 months of manual modeling in its first week and underwrote deals bringing 4M access-plan customers and 3M general customers.
