# Shipra Sonal — Portfolio

Live at **[shiprasonal.com](https://shiprasonal.com)** · Built with Vite + React + TypeScript + Tailwind + Framer Motion.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Auto-deploys to GitHub Pages via `.github/workflows/deploy.yml` on every push to `main`.

## Structure

- `src/portfolioData.ts` — all content (about, experience, projects, skills)
- `src/components/` — Hero, Projects, Experience, Skills, Interests, PhotoStrip, etc.
- `public/photos/` — portrait and travel photography
- `public/video/` — 6–8s looping clips (hero, gym, travel dumps)

Designed with warmth, a little caffeine, and the firm belief that portfolios don't have to be boring.
